### 体积优化数据点
- **零 HAL/标准外设库**：直写 RCC / GPIO / USART1 / FPEC / IWDG / SysTick / SCB 寄存器，整个 Bootloader（含 FPEC 擦写、双页 Meta、WAL 状态机、分包协议栈、CRC16 + CRC32、6 步安全跳转）仅 **4,784 B**，距 8 KB 红线仍有 **3,408 B** 余量。
- **半字节查表法 CRC32**：使用 16 项 `uint32_t` 查找表（仅占 **64 B Flash**、**0 B RAM**），相比传统 256 项全表（1,024 B）节省 **960 B**（近一整页 Flash），同时与 Python `zlib.crc32` 逐比特严格一致。
- **向量表与重定位校验**：全部 3 个 App 镜像的 `Reset_Handler` 均落于 `0x08002101`（满足 `[0x08002000, 0x08008000)` 且 Thumb bit0 = 1），`MSP` 落于 `0x20000000~0x20005000` 且 4 字节对齐，确保 `boot_check_vector_table()` 准确拦截非法镜像。

## 二、PC 端白盒单元测试报告（`firmware/tools/test_boot.c`）

### 测试方法
在 PC 端以 MinGW GCC `-std=c99 -O2 -Wall -Wextra -Werror` 直接编译真实中间件源码 `boot_meta.c`、`iap_proto.c`、`crc16.c`、`crc32.c`，替换 `bsp_flash.c` 为严格模拟 STM32F103 NOR Flash 物理特性的桩模块：
- 强制拦截 `< 0x08002000` 擦写、非半字对齐、跨页编程；
- 强制校验 NOR 物理特性（只允许 `1→0`，未擦除写 `0→1` 立即返回 `BSP_FLASH_ERR_PROG`）；

### 4.2 串口传输吞吐分析（9600 bps）
- 9600 bps（8N1 = 10 bit/Byte）物理层理论极限为 **960 B/s**。
- 每 128 B 数据包携带 9 B 帧头/CRC16 + 11 B 应答帧 = 148 B 往返字节，外加每 8 包一次 Flash 页擦除（~20 ms）与 Meta 双页落盘。
- 实测 3,824 B 固件耗时 **4.94 s**，有效载荷吞吐率达 **774 B/s**（占 9600 bps 理论线速 **80.6%**），全程零丢包、零重传。

## 五、测试期间发现并修复的真实工程缺陷

### 缺陷 1：WAL 第 0 页掉电边界误判（由 PC 93 步穷举测试捕获）
- **根因**：在 `boot_process_startup()` 中，原代码在 `BOOT_STATE_PENDING_INSTALL` 下仅以 `if (m->swap_page_idx == 0u)` 判断是否尚未开始交换并对 Slot 执行整包 CRC32 校验。但若第 0 页已进入 WAL 阶段 B（`WAL_SCRATCH_TAG_ADDR == (WAL_TAG_MAGIC | 0)` 且已开始擦写 `Slot[0]`）时突然掉电，重启时 `swap_page_idx` 尚未递增仍为 `0`，此时校验 Slot 必然失败并错误退回 `NORMAL`，导致 App/Slot 混页。
- **修复**：在 `boot_meta.c` 中同时读取 `WAL_SCRATCH_TAG_ADDR`，仅当 `m->swap_page_idx == 0u && tag_val != (WAL_TAG_MAGIC | 0u)` 时才校验 Slot，否则直接进入 `swap_app_and_slot()` 从 WAL 暂存页续搬；同时检查交换末尾擦除 TAG 页的返回值。
- **验证**：经 `test_boot.c` 穷举第 1..93 步擦写撕裂掉电及双次连续掉电回归测试，恢复成功率 **100%（93/93）**。

### 缺陷 2：无 `pyserial` 环境的上位机串口兼容性
- **现象**：部分 Windows Python 3.13 环境未安装第三方 `pyserial`，导致真板升级脚本启动报错。
- **修复**：在 `firmware/tools/upgrader.py` 中基于 Python 标准库 `ctypes` 封装了原生 Win32 串口后端 `_Win32Serial`（`CreateFileW` / `SetCommState` / `SetCommTimeouts` / `PurgeComm`），未安装 `pyserial` 时自动无缝降级接管，并在 `COM3` 上跑通全部 5 项真板实测。
